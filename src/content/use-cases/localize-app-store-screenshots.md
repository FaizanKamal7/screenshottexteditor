## How it works

1. **Upload your base screenshots.** We detect every text run — headlines, captions, button labels — and hand you back an editable list, no Figma file needed.
2. **Edit the CSV.** Export the detected strings as a CSV, fill in a column per target language (or paste in what your translation vendor already sent you), and upload it back.
3. **Download the ZIP.** We re-render every screenshot in every language, matching the original font, weight, size, color, and baseline pixel-for-pixel — and apply your chosen reflow rule (shrink, expand, wrap, or truncate) wherever translated text runs long.

Nothing here is generative. Each string is rendered with the actual matched font at the actual matched size, so a French screenshot and an English screenshot look like they came from the same design file — because structurally, they did.
